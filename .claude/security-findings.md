# Security findings

Findings from `/security-audit`. Triaged by humans, not auto-fixed.

State lifecycle: `open` → `in-progress` → `fixed` | `accepted` | `deferred`.
- `accepted`: team has decided not to fix (e.g., risk doesn't apply to
  the local-single-user threat model). The auditor will skip on rerun.
- `deferred`: not now, scheduled for later.
- `fixed`: keep the entry for history; auditor skips.

Critical findings get explicit chat callouts on every audit run until
they're closed. Add new entries at the bottom; never renumber.
